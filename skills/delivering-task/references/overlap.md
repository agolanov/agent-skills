# Overlap

Two units may not have live windows at the same time when their plans name a common path. The check is advisory and cheap: a missed overlap only costs a rebase round under `delivering-task`'s main-moved rule, never a wrong merge. Compute each unit's path set once, before the first scheduling.

## Reading a plan

1. Read the whole plan and find every `**Files:**` block: the `**Files:**` line itself and the lines after it, up to the next blank line, heading, or line that is neither a list line nor a line starting with a label (step 2). A checklist item (`- [ ]`, `- [x]`) is not a list line here: a step written directly under the `**Files:**` lines ends the block.
2. Split the block into entries. On the `**Files:**` line read the text after `**Files:**`; on each following line, the line after any leading `- `. A label is a word starting with a capital letter, directly followed by `:` and then a space or the line's end, outside backticks and parentheses: `Modify:` and `Read:` are labels; `Makefile:12` is not, and nothing inside `` `src/Modify: x.sh` `` or `(function Foo: bar)` is, so a trailing parenthetical stays in its entry for step 3 to drop. Every label starts a new entry that runs to the next label or the line's end, so one line may hold several entries (`` **Files:** Modify: `a.md`; Test: `t.sh` ``). Text before the first label, when the line does not start with one, is an entry with no label (`` **Files:** `a.md` ``, `` - `a.md` ``, `**Files:** src/a.sh`). Drop the separators between entries (`,`, `;`) and the spaces around them. Only entries labeled `Create:`, `Modify:` or `Test:` and entries with no label count; an entry with any other label (`Read:`, `Docs:`) does not, and its paths never join the entry before it. Shared test material is edited in the main checkout, where neither worktrees nor rebasing isolate writes, so `Test:` paths count exactly like the others.
3. From each counted entry take every backticked span as one path. Without backticks, split on commas the entry's text after its label, or all of it when it has none. Drop a trailing parenthetical (`(new)`, `(function foo)`) and a trailing line range (`:123`, `:123-145`).
4. Normalize each path relative to the project checkout: strip `./`, resolve `..`, turn an absolute path inside the project into its relative form. Use the installed runtime's ordinary path APIs, such as PowerShell `[IO.Path]::GetFullPath($path, $project)` and `[IO.Path]::GetRelativePath($project, $absolute)`; on POSIX resolve existing parents with `cd`/`pwd -P` and handle remaining `.`/`..` components lexically. Do not require GNU `realpath` options. Respect native path roots/separators and filesystem case behavior; an unresolvable path is unknown overlap, so serialize those units until inspected. A path ending in `/`, or naming an existing directory in the project, is a directory.

A task document with no `**Files:**` block (a plain brief, for one) has an empty set and overlaps nothing.

## Comparing units

Units A and B overlap when some path of A equals some path of B, or one of them is a directory containing the other (`src/` contains `src/a.sh`; `src/a` does not contain `src/ab.sh`). Overlap is symmetric and not transitive.

When scheduling, a startable unit is held back if it overlaps a unit with a live window or an earlier unit chosen in the same pass; the earlier unit in queue order goes first and the other waits for its merge. A window left alive by a unit that [queue](queue.md) Input 3 recorded as already merged holds nothing back: its changes are already on main. Name the shared path when reporting why a unit waited.
