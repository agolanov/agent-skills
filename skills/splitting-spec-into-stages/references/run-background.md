# Run in the background

Launch the writing CLI with the brief's recorded settings, omitting each `cli-default` field. Follow [Launch and wait](../../child-sessions/references/run-contract.md#launch-and-wait), [Background recording](../../child-sessions/references/background.md#background-recording) and [Permissions](../../child-sessions/references/run-contract.md#permissions). Each start or resume gets `<runtime>/split-<spec-stem>-run-<n>`, with the smallest unused number.

On a blocked answer, silent exit or verification correction, continue by [Questions and continuation](../../child-sessions/references/run-contract.md#questions-and-continuation). Retain the run directories and use the [background settings record](../../independent-review/references/launch-settings.md#places) for each opening. Report every producer exit and conversation ID.

A worker ending without valid status gets the [one restart](../../child-sessions/references/run-contract.md#launch-and-wait). A second silent exit or launch failure stops with the checkout and runtime files preserved.
