# Run as a native subagent

Start the worker through the host's native controls with the model and effort from Preflight 3. Follow [Launch and wait](../../child-sessions/references/run-contract.md#launch-and-wait) for the prompt and join. On a blocked answer, silent exit or verification correction, use the native conversation as described in [Questions and continuation](../../child-sessions/references/run-contract.md#questions-and-continuation).

Use the [native settings record](../../independent-review/references/launch-settings.md#places) for each opening.

A worker ending without valid status gets the [one restart](../../child-sessions/references/run-contract.md#launch-and-wait). A second silent exit or launch failure stops with the checkout and runtime files preserved.
